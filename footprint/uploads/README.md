# Uploads (Partner drop zone)

Drop raw inputs for the heat-usage / footprint work here. For example:
- BERDO building rows (CSV/JSON) for the Markley / Boston baseline
- PUE / WUE reference figures (notes, screenshots-as-citations, CSVs)
- Grid carbon-intensity numbers for the site's utility
- Any spreadsheets or calculations behind your footprint numbers

Keep a short note next to each file saying where it came from (source URL / agency) so we can
cite it in the submission. Don't upload anything with secrets or private data.

This folder is tracked in git so your uploads sync to the team.
