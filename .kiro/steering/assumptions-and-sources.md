# Steering: Every number shows its assumption and source

This is the rule that makes Perennial credible to judges. Apply it everywhere.

## Rules
1. **No hidden magic numbers.** Every assumption (collection efficiency, melt loss, PUE, WUE,
   chiller COP, grid CO₂) is an explicit, named, adjustable input with a sensible default — never
   buried in a formula.
2. **Every figure cites a source.** When stating a real-world number, name the agency/program and
   link the official page. Cite NOAA/NCEI, NWS, USGS, LBNL/DOE, Brookings, Boston/MassGIS as used.
3. **Cross-check independent estimates.** Where two methods can estimate the same quantity (e.g.
   geometric vs. empirical collected snow), compute both and show them side by side. Flag large
   divergence rather than hiding it.
4. **Label modeled vs. measured.** If a value is modeled (e.g. a data center footprint derived
   from floor area + LBNL PUE/WUE), say "modeled" and show the basis. Never present a modeled
   number as measured.
5. **State uncertainty honestly.** Prefer a range or a labeled assumption over false precision.
   Forecasts within ~7 days use NWS; beyond that, use climate normals and say so.

## Citation style
Inline links: `[Brookings](https://...)`. Add "Content rephrased for licensing compliance" when
summarizing a source closely.
